AMBIKA JEWELLERS iPhone PWA v2
=============================
This is the installable web-app build. It needs to be opened from an HTTPS web address for iPhone's "Add to Home Screen" / standalone app mode. Opening the HTML directly from the Files/Zapya preview will NOT install/run it correctly.

Once hosted:
Safari -> Share -> Add to Home Screen -> Add.
Data is stored locally in the app/browser using localStorage, and the app includes Export/Import Backup.

This is still a prototype. It is not an App Store signed IPA.
